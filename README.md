# 420 kc

`420 kc` is the small RuneLite plugin that kicked off the broader 420kc / Kill Clog ecosystem.

It celebrates your 420th boss kill count with a chat message, configurable milestone behavior, and a deliberately simple plugin-hub footprint.

## what it does

- watches boss kill counts and catches the exact `420` moment
- highlights the milestone in chat with a celebratory message
- supports multiple milestone display modes depending on how cursed you want the number fixation to be

## Features

- Detects when any boss kill count hits exactly 420
- Sends a celebratory message in chat
- Can be toggled on/off in plugin settings

## why this repo matters

This is the origin point of the wider 420kc ecosystem that later grew into Kill Clog, web surfaces, and the surrounding product tooling.
